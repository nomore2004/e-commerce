# ProcureX Rules & Architecture Guidelines

## Backend Stack & Standards
- **Framework**: FastAPI
- **ORM & DB**: SQLAlchemy 2.0 (using `Mapped`, `mapped_column`), Alembic, PostgreSQL
- **Validation**: Pydantic v2
- **Auth**: JWT with `python-jose`, `passlib[bcrypt]`

## Admin Panel Requirements
- All admin routes live under `/admin` and require the `require_admin` dependency.
- **Every admin write action must create an `AuditLog` row.**
- Never hardcode secrets; use `.env` and maintain `.env.example`.
- Write `pytest` tests for every new endpoint.
- Make small, descriptive git commits; never rewrite unrelated files.
- Ask for approval of the plan before large changes.
