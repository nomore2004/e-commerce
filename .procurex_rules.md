# ProcureX Rules & Architecture Guidelines

## Backend Stack & Standards
- **Framework**: FastAPI
- **ORM & DB**: SQLAlchemy 2.0 (using `Mapped`, `mapped_column`), Alembic, PostgreSQL
- **Validation**: Pydantic v2
- **Auth**: JWT with `python-jose`, `passlib[bcrypt]`

## Admin Panel Requirements
- All admin routes live under `/admin` and require the `require_admin` dependency.
- **Every admin write action must create an `AuditLog` row.**
- Never hardcode secrets; use `.env` and maintain `.env.example`.
- Write `pytest` tests for every new endpoint.
- Make small commits after every single working step. Never rewrite unrelated files.
- Revert commits if something goes wrong rather than re-prompting.
- Keep each task small (e.g., "verification endpoints + tests" or "one frontend view"), not broad features at once.
- Use Planning mode for new modules and Fast mode for quick fixes/tweaks.
- Ask for approval of the plan before large changes.

## Frontend Stack (Ant Design Decision)
- **Framework**: React + Vite + TypeScript
- **UI Library**: **Ant Design (`antd`)** (Selected for out-of-the-box Table, Form, Modal, Tag, and Statistic components that minimize assembly work and token/task overhead)
- **State & Data Fetching**: TanStack Query (`@tanstack/react-query`)
- **HTTP Client**: Axios
- **Icons**: `@ant-design/icons`
